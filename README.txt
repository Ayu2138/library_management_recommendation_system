LIBRARY MANAGEMENT SYSTEM

Files:
- main.py: The Python program.
- books.csv: Sample book records. The program updates this file automatically.

How to run:
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Open the terminal in that folder.
4. Run: python main.py

Features:
1. Add book
2. View books
3. Search by part of a book title
4. Update a book using its title
5. Delete a book using its title (asks for confirmation)
6. Issue a book using its title
7. Return a book using its title
8. Generate a report

Important:
- Enter the exact book title for update, delete, issue, and return.
- Search supports partial titles.
- Keep main.py and books.csv in the same folder.
- Make a backup of books.csv before testing delete operations if you want to preserve the sample data.
